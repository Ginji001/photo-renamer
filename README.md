# 撮影日時リネーマー

写真・動画（AVI）のファイル名を、撮影日時（例：`2026-09-17_151124.AVI`）に変更するPWAです。
処理はすべてブラウザ内で行い、ファイルは外部へ送信しません。

## 使い方
1. Google Chrome でこのページを開き、「アプリとしてインストール」（またはアドレス欄右のインストールアイコン）を押す
2. アプリを起動し「フォルダを選択」→ SDカードの「DCIM」フォルダを選ぶ
3. 「編集を許可」を押す
4. 一覧を確認して「名前を変更」→「変更する」

- 同じ秒のファイルには `_001`, `_002` が付きます
- 同じ名前のファイルがある場合は上書きしません
- 変更直後は「元に戻す」で戻せます
- 「別のドライブにコピー」で、変更後の名前のまま外付けHDなどへコピーできます（日付フォルダ分けも可、上書きなし）
- Safari ではファイル名の変更はできません
