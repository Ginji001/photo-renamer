# 撮影日時リネーマー

写真・動画（AVI）のファイル名を、撮影日時（例：`2026年09月17日_15時11分24秒.AVI`）に変更するPWAです。
処理はすべてブラウザ内で行い、ファイルは外部へ送信しません。

## 使い方
画面上の4つのボタンを左から順に押します（次に押すボタンが青くなります）。

1. **フォルダを選ぶ** … SDカードの「DCIM」を選び「編集を許可」
2. **名前を変更** … 撮影日時の名前に変更（直後なら「名前を元に戻す」で戻せます）
3. **HDにコピー** … チェックしたファイルを外付けHDなどへコピー（上書きなし）
4. **SDから削除** … チェックしたファイルを削除。コピー済みはコピー先と照合してから削除

削除後は Finder で ⏏（取り出し）してから抜き、カメラでフォーマットしてください。
SDカードのファイルは Finder でゴミ箱に入れないでください（カード上のゴミ箱に残り、容量が空きません）。
Google Chrome 専用です（Safari では使えません）。
